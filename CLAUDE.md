# Правила вайбкодинга для этого проекта

## Пошаговая работа с VPS / деплоем

Когда нужно что-то выполнить на VPS пользователя (или в любом окружении, куда
у Claude нет прямого доступа):

- Давать **ровно один шаг** (одну команду или маленькую группу команд одного
  действия) за раз.
- После шага — **остановиться и ждать**, пока пользователь выполнит команду
  и напишет результат/подтверждение.
- **Не** выдавать сразу весь план из нескольких шагов вперёд.
- Переходить к следующему шагу только после того, как пользователь явно
  подтвердил, что предыдущий выполнен (прислал вывод, написал "готово",
  "дальше" и т.п.).
- Если шаг мог пойти не так — прежде чем давать следующую команду, попросить
  вывод/лог, чтобы убедиться, что всё прошло штатно.

Это касается любых операций на сервере пользователя: установка, настройка
pm2/nginx/firewall, работа с ключами, миграции БД и т.д. — везде, где Claude
не выполняет команды сам, а только выдаёт их пользователю на выполнение.
