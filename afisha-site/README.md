# afisha-site — фронтенд афиши (afisha.ekb-guide.ru)

Не бот, не разворачивается на VPS через Supervisor. Это статические файлы
сайта афиши на Timeweb: vanilla JS + supabase-js v2 (`index.html`,
`admin.html`, `embed.js`) + PHP 7.4 для SEO-страниц событий (`event.php`,
`sb-config.php`). Обновлённые файлы заливаются на Timeweb вручную, поверх
существующих.

## Что изменено в этой версии

1. **Время в выдаче — только часы, без минут** («19 часов», «23 часа», с
   правильным русским склонением). Правка на отображении:
   - `sb-config.php`: `hour_word()` + `sched_text()` — используется в
     `event.php` (список событий и человекочитаемая дата на странице события).
   - `embed.js`: `hourWord()` + `fmt()`.
   - `index.html`: `hourWord()` (для показа) — `fmtTime()` (сырой `HH:MM`)
     оставлен как есть и используется только для сортировки событий дня по
     времени, чтобы не сломать порядок.
   - В базе `start_time`/`end_time` ничего не меняется. В `event.php`
     Schema.org `startDate`/`endDate` (через `iso_dt()`) остаются в полном
     ISO — не тронуты, это отдельная функция.

2. **Логотип/фото заведения + подстановка в превью для видео-анонсов.**
   - `sql/venues_logo.sql` (в `../afisha-bot/sql/`) — добавляет
     `venues.logo_url`/`logo_path`. Выполнить в Supabase один раз.
   - `admin.html`: в форме площадки — загрузка логотипа (файлом или ссылкой),
     переиспользует бакет `event-posters` с префиксом `venues/`. У события
     обложка обязательна, **кроме** случая, когда у выбранной площадки уже
     есть логотип (тогда его подставит виджет — см. ниже).
   - `index.html`, `embed.js`: приоритет картинки превью-карточки —
     `cover_image_url`, иначе `venue.logo_url`, иначе плейсхолдер. В модалке
     `index.html` логотип **не** подставляется — постер там показывается,
     только если это реальная афиша события; видео проигрывается как обычно.
   - `event.php`: та же цепочка приоритетов, но только для OG/Twitter/
     Schema.org превью-картинки (`$previewImage`) — видимый `<img class="poster">`
     на самой странице остаётся строго от `cover_image_url`, логотип туда не
     подставляется (чтобы не дублировался рядом с видео).

## Деплой

1. Выполнить `../afisha-bot/sql/venues_logo.sql` в Supabase (если ещё не
   выполнялся).
2. Залить обновлённые `admin.html`, `index.html`, `embed.js`, `event.php`,
   `sb-config.php` на Timeweb поверх текущих файлов сайта.
3. Проверить: в списке/модалке время показывается часами; у площадки с
   логотипом видео-анонс без своей афиши показывает логотип на карточке.
