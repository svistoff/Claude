# posmon — мониторинг позиций сайтов в Яндексе

Веб-система ежедневного мониторинга позиций сайтов в органической выдаче Яндекса
по заданным запросам, с историей, графиками, метриками и PDF-отчётами.

Спецификация: [`../docs/yandex-position-monitoring-tz-v2.md`](../docs/yandex-position-monitoring-tz-v2.md).
Развёртывание: VPS `magic-copper`, домен `stat.xmassage.vip`, под Supervisor + nginx.

## Архитектура

```
posmon/
  domain/        чистая доменная логика (без БД и сети):
    results.py     типы результатов выдачи (organic/business/ad/...), статусы
    normalize.py   нормализация доменов, режимы сопоставления (domain/exact_host)
    position.py    расчёт органической позиции + позиции в блоке Бизнеса
    metrics.py     средняя (без NULL) + coverage, медиана, ТОП-3/10/20/50
  providers/     источники выдачи (в разработке):
    base.py        интерфейс SearchProvider
    yandex_api.py  официальный Yandex Search API — непесонализированные профили
    browser.py     Playwright + Chromium — персонализированные профили
    mock.py        мок для тестов/разработки
  models.py      схема БД (SQLAlchemy)         [в разработке]
  web/           FastAPI + серверная админка   [в разработке]
  tests/         юнит-тесты доменной логики
```

### Стратегия сбора (раздел 1 ТЗ v2)

- **Официальный Yandex Search API** — профили без персонализации (Новый,
  Desktop, Mobile): регион `lr=54` + устройство. Легально, без капчи и прокси.
- **Браузерный скрейпинг** (Playwright с VPS) + сервис распознавания капчи —
  персонализированные профили (Екатеринбуржец, Приезжий).
- Прокси — опциональный запас на рост блокировок, не требование MVP.

### Ключевые принципы

- Единица работы — выборка выдачи (`запрос × профиль`); сайты матчатся по уже
  скачанной выдаче без доп. запросов.
- Позиция — по органике; колдунщики и реклама пропускаются; дубли домена → лучшая
  позиция; блок Бизнеса трекается отдельно.
- Техническая ошибка (ERROR/BLOCKED/CAPTCHA) **никогда** не пишется как позиция.
- Полная выдача сохраняется для аудита и пересчёта позиции.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r posmon/requirements.txt
.venv/bin/python -m pytest posmon/tests -q      # из корня репозитория
```

`.env` — по образцу [`.env.example`](.env.example).

## Запуск (локально)

```bash
.venv/bin/uvicorn posmon.asgi:app --host 127.0.0.1 --port 8010   # админка
.venv/bin/python -m posmon.scheduler                              # ежедневный прогон
```

Первый вход — логином/паролем из `POSMON_ADMIN_LOGIN`/`POSMON_ADMIN_PASSWORD`.
